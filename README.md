# MMH Places

Integração da **My Magic Home** para Home Assistant: mercados, academias, farmácias e outros
estabelecimentos perto da casa, com favoritos, zonas automáticas e horário de funcionamento.

Instalação pelo HACS (repositório personalizado, tipo **Integração**). Precisa do token de
cliente fornecido pela My Magic Home.

Os cards do dashboard (**Meus estabelecimentos** e os mercados abertos na lista de compras)
fazem parte do **MMH Cards**.

Uso exclusivo em instalações de clientes My Magic Home. Ver `LICENSE`.
Suporte: fale com a My Magic Home.
